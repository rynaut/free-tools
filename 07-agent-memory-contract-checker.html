Agent Memory Contract Checker

Memory APIs are commoditising fast — the differentiator now is the contract around them. Check your agent's memory layer against the eight properties a robust contract needs, or paste your schema and have it validated against the contract pattern directly.

WHY NOW   Open memory layers (supermemory and peers) cross 25K+ GitHub stars and memory APIs are commoditising. When the API is a commodity, the architecture — the contract — is the moat. This tool is free; it builds toward Rynaut's regulated-AI and architecture work.

Bolting a memory layer onto an agent is easy — the API is one call. What breaks systems in production is the missing contract: no write policy, no schema guarantees, no expiry, no defined failure behaviour. State accumulates, goes stale, and fails in ways that are painful to debug. This tool checks both the design properties of your contract and the structure of your actual schema, and hands you a reference schema to copy.
