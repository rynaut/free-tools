You have an AI-generated output in front of you.
Apply this framework before accepting, revising, or rejecting it.
↓
GATE 1 · GROUNDING
Can every factual claim in this output be verified against a known source?
Numbers, names, citations, dates, API names, URLs — anything checkable.
YES ↓NO →
Proceed to Gate 2
REVISE
Flag unverified claims. Verify or remove before accepting.
Do not accept outputs with unverifiable factual assertions in production contexts.
↓
GATE 2 · SCOPE
Does this output stay within the scope of what was asked — no added assumptions, scope creep, or unsolicited decisions?
AI models often solve an adjacent problem or make implicit decisions the user didn't request.
YES ↓NO →
Proceed to Gate 3
REVISE
Strip additions outside the original scope. Rerun with a tighter prompt if needed.
↓
GATE 3 · CONSEQUENCE
Is the blast radius of acting on this output low — meaning a mistake is cheap to reverse?
Sending an email, deploying code, deleting data, or publishing content all have different reversal costs.
YES ↓NO →
Proceed to Gate 4
HUMAN REVIEW
High-consequence outputs require a human in the loop before action. Add an approval step.
Zero Blast Radius principle: if you can't reverse it fast, don't automate the final step.
↓
GATE 4 · CONSISTENCY
Does this output match what the same model produced last time for a similar input — or has something changed unexpectedly?
Inconsistency signals model drift, prompt regression, or context pollution.
YES ↓NO →
Proceed to Gate 5
INVESTIGATE
Don't accept inconsistent output blindly. Check prompt, context window, and model version before proceeding.
↓
GATE 5 · BIAS & SAFETY
Is this output free of harmful bias, discriminatory framing, or content that creates legal or reputational risk?
Customer-facing, hiring, legal, and medical outputs carry the highest risk surface.
YES ↓NO →
Proceed to Gate 6
REJECT
Do not accept. Rewrite with explicit constraints. Log the failure pattern for your eval suite.
↓
GATE 6 · COMPLETENESS
Does this output fully address the task — no missing steps, omitted edge cases, or partial answers presented as complete?
Partial completion presented as done is more dangerous than an obvious failure.
YES ↓NO →
Proceed to Gate 7
REVISE
Identify missing elements explicitly. Prompt for the gaps rather than accepting an incomplete answer.
↓
GATE 7 · OWNERSHIP
Can a named human take responsibility for the accuracy and consequences of this output?
If no one would put their name on it, it is not ready to ship.
YES ↓NO →
All Gates Passed
HOLD
Do not ship AI output that has no accountable owner. Assign ownership first.
↓
